DineTrack: restaurant order management system

DineTrack is a menu-driven restaurant ordering program written in C. Customers browse the menu and build an order, and employees manage the menu and view sales reports. Our team of four split the program into separate modules for menus, orders, billing, receipts, files, and the user interface.

I built the user interface and receipt generation modules. The user interface handles the customer and employee menus, checks that input is valid, and shows error and confirmation messages. The receipt module checks that an order is confirmed, then builds a formatted receipt from the order and billing information. We followed test-driven development, wrote test cases in Visual Studio, and documented each module in a team report.
